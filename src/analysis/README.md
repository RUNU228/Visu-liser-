# Continuous analysis API

`worker.ts` is the browser Worker entry. `AnalysisWorkerHost` exposes the same protocol for deterministic tests. PCM buffers are `Float32Array` interleaved `L,R`, with exactly `sampleFrameCount` stereo frames used; unused pool capacity is ignored. Every PCM buffer is returned via a `recycle` message and transfer, including rejected packets. At most three result messages may be outstanding. Return one credit after retaining a result. Send `tick.currentFrame` from the AudioContext clock to reject packets whose latest sample is more than 100 ms old.

`AnalysisEngine` contains the continuous numerical state. A gap/epoch resets FFT, filters, detector, smoothing, peaks and short paired history. Numerical task revisions clear only that task's incompatible state. The raw paired ring retains 300 ms; the main thread owns waveform, spectrogram and visual persistence histories. Results use capture sample timing plus `visualStart`, never arrival time.

- Waveform returns **new completed ~2 ms buckets** with all L/R/M/S extrema, sums of squares and sample counts. `lastFrame` is exclusive. Optional band values are separate LR4 RMS measurements.
- Spectrogram returns **new completed sample-timed 10 ms groups**, taking maximum unsmoothed power within each group. Fixed logarithmic storage edges remain independent of display scale, trim and floor. `firstFrame`/`lastFrame` identify included STFT centers (possibly fractional); `start`/`end` identify the union of their half-hop time supports for display placement; FFT time resolution remains N/Fs. One unfinished group remains in the worker until the following STFT group arrives.
- Spectrum is the latest calibrated, temporally smoothed power snapshot; `time` is its STFT center, `latestFrame` the window's last captured sample. Peaks use pre-trim/pre-tilt levels, 500 ms hold and 12 dB/s decay.
- Stereometer returns **only newly selected complete 1 ms buckets**, with stride 9 rows `[visualTime,L,R,lowL,lowR,midL,midR,highL,highR]`. Keep rows in main once; opacity is full through `windowMs`, then `exp(-(age-window)/tau)`, removing below 1/255. The result also contains current 100 ms dot-product correlation and shared automatic gain. The same selected rows result from different PCM batch sizes. Desktop uses at most 24 pairs/ms; mobile/economy 12. Both channels below −100 dBFS RMS insert no points.
- Oscilloscope contains actual PCM resampled onto a uniform fractional-endpoint grid, including both endpoints. `duration` is seconds. Complete reliable YIN selects 1/2/4 periods; otherwise Free duration applies. Pitch startup shows Preparing until the detector window is complete. Triggers search at most 100 ms before the latest permitted complete window and apply 0.01 hysteresis. `startFrame` is fractional for interpolated crossings. Frequency is null after a failed current YIN check or gap.

`dsp.ts` exports renderer-safe pure helpers: `channelValue`, `powerDb`, `encodeDb`, `decodeDb`, `combineStats`, `frequencyPosition`, `frequencyAt`, `aggregateFrequency`. Code 0 is exact silence or ≤−160 dBFS; code 65535 is ≥+160 dBFS. Neither endpoint is an exact bounded measurement. `powerDb(0)` returns −Infinity; renderers must clamp at their configured display floor. Log/Mel bucket interpolation is identified explicitly and adds no frequency resolution.

Tests generate deterministic PCM directly, independent of browser decoders. They verify FFT bin-centered calibration (750 Hz at Fs=48 kHz/N=4096), DC/Nyquist exceptions, anti-phase energy, Hann/Blackman, exact power decay, quantization, crossovers, YIN, trigger interpolation, fixed pair selection, gaps, revisions, actual transfer ownership and credits. Browser playback/performance and the renderer's age-based persistence need separate integration verification.
